# Gym Plan Buddy

Kleine statische Webseite, um:
- Muskelgruppe auszuwählen
- passende Übungen zu sehen
- Gewicht, Wiederholungen und Sätze zu speichern
- Verlauf lokal im Browser zu tracken

## Start

Einfach `index.html` im Browser öffnen.

## Hinweis zu OneDrive

Du kannst die Dateien in OneDrive speichern und teilen. Für eine direkt gehostete URL ist ein Webhoster wie GitHub Pages, Netlify oder Vercel meist besser geeignet.
